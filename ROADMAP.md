# Roadmap

Open Local AI Database is meant to become a practical reference for local AI compatibility.

## Near term

- Add source links per record.
- Add license normalization.
- Add runtime support fields: LM Studio, Ollama, llama.cpp, MLX, ONNX.
- Add model-card provenance for Hugging Face records.
- Add hardware fit notes for Apple Silicon and NVIDIA GB10-class machines.
- Add benchmark source fields where public benchmarks are available.

## Medium term

- Add compatibility snapshots by RAM tier.
- Add local AI stack recipes: LM Studio, Ollama, llama.cpp, MLX.
- Add downloadable SQLite database.
- Add changelog entries for new models.
- Add a small generated static viewer.

## Community goals

- Make model suggestions easy.
- Keep correction issues lightweight.
- Prefer source-backed metadata over hype.
- Make the dataset useful enough to be cited by blogs, newsletters and AI tools.
