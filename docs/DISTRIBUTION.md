# Distribution Checklist

Use this repo as a public reference asset, not as a sales pitch.

## GitHub positioning

Suggested repository name:

```text
open-local-ai-database
```

Suggested description:

```text
Open local AI model, TTS, ASR and hardware compatibility database by LocalClaw.
```

Suggested topics:

```text
local-ai, llm, tts, asr, lm-studio, ollama, llama-cpp, mlx, apple-silicon, nvidia, open-data
```

## Places to submit

- Awesome LLM lists
- Awesome local AI lists
- Awesome Ollama lists
- Awesome LM Studio lists
- Awesome MLX lists
- AI tool directories that accept open-source resources
- Hacker News Show HN
- Product Hunt launch materials
- Local AI newsletters
- Apple Silicon developer communities

## Outreach angle

Short version:

```text
I maintain an open local AI compatibility database: 188 LLM records, 57 TTS/ASR speech models and 15 Apple/NVIDIA machine profiles. It maps RAM tiers, quantization, LM Studio search terms and practical local fit.
```

More personal version:

```text
I am trying to make local AI easier to understand. The common question is not only "what is the best model?", but "what can my machine actually run?". This database is the open version of the metadata behind LocalClaw.
```

## Avoid

- Paid backlinks.
- Low-quality directory spam.
- Overclaiming benchmark authority.
- Saying cloud-only models are locally installable.
- Submitting the same pitch everywhere.
